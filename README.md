# Exploratory-Data-Analysis-Churn-Analysis-Customer churn is one of the most critical metrics for subscription-based and service-oriented businesses. The goal of this project is to analyze churn patterns using Python and extract insights that can help a business improve retention.

Through this EDA, I explored:

What factors influence churn?

How customer demographics affect churn probability

Insights from usage patterns

Overall trends showing behavior differences between churned and retained customers

This project uses Python, Pandas, NumPy, Matplotlib, and Seaborn to visualize and interpret churn trends effectively.
